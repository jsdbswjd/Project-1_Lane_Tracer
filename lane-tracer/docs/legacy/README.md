# Legacy

이 디렉토리에는 프로젝트 초기 단계에서 사용한 코드들이 보관되어 있습니다.
실제 운영에는 사용되지 않지만 참고용으로 남겨둡니다.

## `pc_python.py`

micro-ROS로 옮기기 전, 초기 단계에서 ESP32와 raw TCP 소켓으로 통신하던
핸드셰이크 테스트 스크립트입니다. ESP32와의 양방향 통신 동작 검증용이었어요.

`HELLO` → `READY` → `START` → `OK` 순서로 핸드셰이크 후
ESP32가 보내는 데이터를 라인 단위로 출력하고, `Ctrl-C`로 `STOP`을 보냅니다.

> 현재 시스템은 micro-ROS Agent를 통한 UDP 통신으로 대체되었습니다.
> ESP32 펌웨어의 micro-ROS 클라이언트가 ROS 2 토픽으로 직접 통신합니다.
